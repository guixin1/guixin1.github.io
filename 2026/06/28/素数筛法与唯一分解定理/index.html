原理

三、唯一分解定理

定理内容

每个大于 1 的正整数都能唯一地分解为素数的乘积：

$$n = p_1^{a_1} \times p_2^{a_2} \times \cdots \times p_k^{a_k}$$

其中 $p_1 < p_2 < \cdots < p_k$ 为素数，$a_i$ 为正整数。

应用：分解质因数

唯一分解定理的重要应用

应用 公式
约数个数 $\prod_{i=1}^{k}(a_i + 1)$
约数和 $\prod_{i=1}^{k}(p_i^0 + p_i^1 + \cdots + p_i^{a_i})$
约数和公式 $\prod_{i=1}^{k}\frac{p_i^{a_i+1}-1}{p_i-1}$
最大公约数 $\gcd(a,b) = \prod p_i^{\min(a_i, b_i)}$
最小公倍数 $\text{lcm}(a,b) = \prod p_i^{\max(a_i, b_i)}$
